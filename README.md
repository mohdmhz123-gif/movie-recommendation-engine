# Movie Recommendation Engine

A Python-based movie recommendation engine that recommends movies based on a user's preferred genre and minimum rating.

## Features

- Filter movies by genre
- Filter movies by minimum rating
- Sort recommendations by highest rating
- Handle cases where no recommendations are found

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Functions
- Sorting Algorithms

## Example

Enter your favourite genre: Sci-Fi

Enter minimum rating: 8.0

Recommended Movies:

Inception

Interstellar
